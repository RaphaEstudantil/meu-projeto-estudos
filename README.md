# 🚀 Meu Projeto de Estudos

Este repositório foi criado durante a Aula 1 de Versionamento com Git.
Aqui vou testar meus conhecimentos e praticar comandos no terminal!

**Comandos de Inicialização (Criar o projeto):**
```bash
git init
git add .
git commit -m "feat: meu primeiro commit semantico"
git remote add origin <URL>
git branch -M main
git push -u origin main
```

## 🌟 Trabalhando com Branches
Eu acabei de criar um universo paralelo (Branch) e fiz o meu primeiro Pull Request!

**Comandos usados para criar Branch e mandar para PR:**
```bash
git checkout -b feature/minha-branch
# ... faça suas edições de código ...
git add .
git commit -m "feat: nova funcionalidade"
git push -u origin feature/minha-branch
```

## ⚡ Atualização Direta (Trabalho Solo)
Eu também aprendi a fazer atualizações diretamente na branch main, enviando o código direto para a nuvem sem precisar de Pull Request!

**Comandos usados no fluxo direto:**
```bash
# ... faça suas edições de código ...
git add .
git commit -m "feat: atualização rapida"
git push origin main
```
